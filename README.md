# Job Tracker Application

An AI - powered job application to manage job applications, track statuses, schedule reminders, and support future AI features like resume job matching and interview preparation.

## Planned Tech Stack
- Frontend: Next.js / React
- Backend: FastAPI
- Database: PostgreSQL
- AI: Python-based AI Integration

## Planned Features
- Add and manage job applications
- Track application status
- Follow-up Remindiers
- Interview tracking
- Dashboard analystics
- Future AI- Powered Features
